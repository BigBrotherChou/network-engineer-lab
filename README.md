# 网工实训台 · Network Engineer Lab

纯本地离线的**网络工程师学习网页应用**：学习练习华为 / 新华三 / 锐捷三大品牌网络设备命令，并搜索主流设备参数辅助选型。零依赖、零安装，双击 `index.html` 即用。

## 功能

| 模块 | 说明 |
|---|---|
| 命令速查 | 华为 VRP / 华三 Comware / 锐捷 RGOS 三套命令库（每套 40+ 条），按系统管理 / VLAN / 端口链路 / 三层路由 / 安全远程 / 备份升级 / 排障日常 7 类整理；关键词搜索、本地收藏；重点标注跨品牌差异（display↔show、save↔write、undo↔no、Vlanif↔Vlan-interface↔interface vlan 等） |
| 实战演练 | 浏览器内 CLI 仿真终端：三品牌真机风格提示符、支持命令缩写（`dis cu` / `p l a` / `conf t`）、`?` 联机帮助、Tab 补全、分品牌报错格式；16 个配置任务自动判分（华为 6 / 华三 5 / 锐捷 5）+ 自由练习模式 |
| 设备选型 | 30 款主流设备参数库（接入 / 汇聚 / 核心交换机、出口路由器、安全网关），按品牌 / 类型 / 层级 / PoE / 万兆 / 集采常见筛选排序，详情弹窗、2-3 款参数对比、CSV 导出（Excel/WPS 可直接打开） |
| 命令小测 | 30 题题库，按品牌组卷、即时判分解析、错题单独重练、最高分本地记录 |

## 使用方式

双击 `index.html` 即可离线运行（现代浏览器均可），无需安装任何环境；也可放到任意静态服务器上托管。

学习进度、命令收藏、任务完成情况保存在浏览器 localStorage，**不上传任何数据**。

## 目录结构

```
index.html          入口
css/style.css       样式（白底淡蓝 / 紧凑布局 / 毛玻璃弹窗）
js/app.js           路由、模块与数据懒加载、本地进度
js/cli-engine.js    CLI 仿真引擎（三品牌语法 / 缩写匹配 / 视图栈 / 判分状态）
js/data/            命令库 commands-*.js、设备库 devices-data.js、任务库 tasks-data.js、题库 quiz-data.js
js/modules/         命令速查 / 实战演练 / 设备选型 / 命令小测 四个功能模块
```

## 数据说明

- 设备参数与价格区间为公开资料整理，个别数值标注“参考”，**正式选型 / 投标请以厂商官方规格书为准**（页脚提供华为 / 新华三 / 锐捷官网核对入口）。
- 扩充设备、修改题目或命令库：直接编辑 `js/data/*.js`，按现有条目格式追加即可，刷新页面生效。

仅供学习交流使用。
